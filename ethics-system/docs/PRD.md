# PRD — 윤리·징계·광고 업무지원 시스템

| 항목 | 내용 |
|---|---|
| 요청 | 대한변리사회 회원서비스실 (광고: 이대운 차장 / 윤리·징계: 황예진 차장) |
| 근거 자료 | ① 「회원서비스실 윤리징계 및 광고 업무 수행 과정 / AI 업무교육 필요 분야」(HWPX) ② 변리사법·윤리강령·윤리위원회 운영 규정·징계위원회 운영 규정·변리사 광고에 관한 규정(HWP) ③ 대한변협 변호사 징계사례집 게시물(링크) |
| 버전 | 1.0.0 (2026-10-12) |

## 1. 문제 정의
윤리·징계·광고 업무는 **민원 접수 → 민원 검토·소명 → 위원회 심의 → (징계)** 로 진행되며, 다음 작업이 수작업으로 반복된다.

1. 포털·SNS·블로그 광고를 직접 검색하고 캡처해 채증, 위반 여부 1차 판단
2. 사실관계에 맞는 변리사법·광고규정·윤리강령 조항을 찾아 적용
3. 변호사 징계사례집(1~8집)에서 유사 선례와 징계 수위를 찾기
4. 소명 요청·시정 권고·징계 회부 등 공문을 매번 새로 작성
5. 위원회 회의자료(위반사실·소명내용·검토의견) 정리, 녹취 기반 회의록 작성
6. 불이익 처분 대비 — **소명 요청부터 결과 통보까지 모든 절차를 메일 발송 근거로 기록**해야 함

## 2. 목표 / 비목표
**목표**
- 사건 1건의 전 과정(접수~종결)을 한 화면에서 추적하고, 단계·기한·발송 근거를 자동 기록
- AI 교육 요청 5개 분야를 실제 기능으로 제공 (아래 3장)
- AI가 없거나 API 키가 없어도 핵심 기능(규칙·검색)은 동작
- AI 사용 시 **등록된 법조문·규정 안에서만** 근거를 제시하고, 벗어난 답변은 서버가 자동 차단

**비목표(1.0 범위 밖)**
- 포털 자동 크롤링(약관·차단 문제) → 검색어 세트·CSV 일괄 분류로 대체
- 전자결재 시스템 연동(그룹웨어) → 결재권자·결재일 기록 방식
- 변리사 등록 DB 실시간 연동 → 회원 여부 수동 표시

### 3.1 사건 절차(상태 머신)
접수 → 검토 중 → 결재 대기 → 소명 요청(기한 14일 자동) → 소명 검토 → 종결 / 위원회 상정 → 시정 요구(기한 30일) / 징계위원회 회부 / 외부기관 이관(지식재산처·공정위) → 종결
- 허용되지 않은 단계 이동 차단, 결재·종결·회부·이관 등은 **사유 기재 필수**
- 기한 경보: 소명 기한 임박·경과, 시정 기한 경과, **시정 기한 + 1개월 경과 시 징계발의 가능**(광고규정 제12조④), **징계시효 3년**(변리사법 제17조④) 만료 180일 전, 이의신청 기간(30일), 비회원(자체 처분 곤란)
- 처리 경과는 삭제·수정 불가 기록(타임라인)

### 3.2 비기능 요구사항
- 인증: 아이디/비밀번호, PBKDF2-SHA256(39만 회), 5회 실패 시 15분 잠금, 최초 로그인 비밀번호 변경 강제, 세션 10시간
- 권한: 관리자 / 담당자 / 조회 전용
- 보안: HttpOnly·SameSite=Strict 쿠키, CSRF 토큰, CSP·X-Frame-Options, 업로드 확장자·크기 제한, 경로 조작 방지, 모든 변경 감사 로그
- 백업: SQLite 온라인 백업 + 첨부 tar.gz, 보존 개수 관리, 관리 화면·cron
- 사내망 단일 서버 운영(외부 의존 없음), 모바일 화면 대응
