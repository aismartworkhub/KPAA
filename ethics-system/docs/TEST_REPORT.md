## 2. 화면 E2E (Playwright, Chromium) — 21단계 전부 통과
로그인 → 최초 비밀번호 변경 강제 → 대시보드 → 사건 목록·상세 → 스크리닝 결과 '위반 소지 인정' → 근거 분석·조문 적용 → 단계 변경 3회(결재 사유 입력) → 소명 요청 공문 자동 작성 → 확인 필요 항목 결재 차단 확인 → 기본 설정(연락처·결재선) → 공문 재작성·결재·발송 기록 → 처리 경과 MAIL 확인 → .docx 다운로드 → 모니터링 스크리닝 → 규정 매칭 → 선례 검색 → 회의 등록·안건·의결·회의자료·의결 반영·녹취 정리·회의록 저장 → 모바일(390px) 레이아웃

- 브라우저 콘솔 오류: 없음 (로그인 전 세션 확인 401, 의도된 결재 차단 400만 발생)
- 테스트 중 발견·수정: 비동기 처리 후 버튼 참조 오류(`e.currentTarget` null) 5곳, 회의 수당 표시 저장 누락, 삭제된 조문이 매칭 후보에 섞이는 문제, SQLite 스레드 오류
