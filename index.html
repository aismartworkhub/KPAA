이미지 생성 AI는 글자를 '문자'가 아니라 '그림 조각'으로 그립니다. 한글처럼 획이 많은 문자는 특히 붕괴합니다. 그래서 글자를 AI에게 시키지 않는 것이 유일하게 확실한 해법입니다.

① DB 구조 설계Claude · ChatGPT
대한변리사회 정책홍보실의 노션 DB를 설계하려 한다. 우리가 쌓는 자료는:
보도자료, 뉴스레터, SNS 콘텐츠, 일일보도, 회의록, 법제도 연구자료, 의견조회 대응 기록.
이 목록에 있는 자료 유형만 대상으로 DB 3개(홍보 콘텐츠 / 언론보도 아카이브 / 법제도 자료)의
속성(컬럼) 구성을 표로 제안해줘.
- 각 DB: 속성명 / 속성 유형(선택·날짜·사람·URL 등) / 예시 값 1개
- 공통 속성에 반드시 "검수 상태(초안/검수 중/확정)"와 "보안 등급(공개/내부)"을 포함할 것.
- 우리가 이해 못 할 전문용어는 쓰지 말 것. 제안이며 확정은 부서 협의로 한다.
② 축적 자료 일괄 태깅Claude · ChatGPT
아래는 아카이브에 등록할 기존 자료 목록(제목·날짜·첫 문단)이다. [자료 목록 붙여넣기]
제공한 목록만 대상으로 각 자료에 다음을 달아줘:
- 주제 태그(최대 2개): 변리사제도 / 지식재산정책 / 협회활동 / 회원서비스 중에서만
- 1줄 요약(자료에 있는 내용만) / 보안 등급 추천(공개·내부)과 그 이유 1줄
- 판단이 어려우면 태그 대신 "[담당자 확인]"으로 표시. 등급 확정은 사람이 한다.
