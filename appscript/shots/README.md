# 실제 화면 캡처 폴더

교안(`../index.html`)의 각 화면에는 ID(예: `m1-03`)가 붙어 있습니다.
이 폴더에 `<화면ID>.png` 이름으로 실제 캡처를 넣으면, 교안을 열 때 모형 화면 대신 실제 캡처가 자동으로 표시됩니다.
(그림 아래 ‘모형 보기’ 버튼으로 다시 모형과 비교할 수 있습니다.)

찍을 화면 목록은 교안 **부록 G. 화면 캡처 목록**에 자동으로 정리됩니다.

캡처 시 주의
- 실습 시트(가상 데이터)로만 캡처하고, 실제 회원 정보가 보이는 화면은 찍지 않습니다.
- 계정 이메일 주소가 보이면 가리고 저장합니다.
- 가로 1280px 안팎 브라우저 창에서 해당 부분만 잘라 저장하면 보기 좋습니다.
